# setup.tg — гайд по подключению бота в Telegram

Интерактивный сайт-инструкция с настоящими отзывами, которые хранятся в базе данных
(Neon Postgres) через простой backend на Express.

## Структура

```
project/
├─ server.js        # Express-сервер + API /api/comments
├─ package.json
├─ .env.example      # шаблон для локальной разработки
└─ public/
   └─ index.html     # весь сайт (канвас, инструкция, форма отзывов)
```

## 1. Создать базу на Neon

1. Зарегистрируйтесь на [neon.tech](https://neon.tech) и создайте новый проект.
2. В разделе **Connection Details** скопируйте **Connection string** — он выглядит так:
   ```
   postgresql://user:password@ep-xxxxxxxx.us-east-2.aws.neon.tech/neondb?sslmode=require
   ```
3. Это и есть ваш `DATABASE_URL`. Таблица `comments` создастся автоматически при первом
   запуске сервера — руками ничего создавать не нужно.

## 2. Запуск локально (проверить перед деплоем)

```bash
cd project
npm install
cp .env.example .env
# вставьте свой Neon connection string в .env вместо примера
npm start
```

Откройте `http://localhost:3000` — сайт должен загрузиться, а отзыв, оставленный внизу
страницы, — сохраниться в базе (обновите страницу, чтобы проверить).

## 3. Деплой на Render

1. Залейте папку `project/` в репозиторий на GitHub.
2. На [render.com](https://render.com): **New +** → **Web Service** → подключите репозиторий.
3. Настройки сервиса:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Environment:** Node
4. Во вкладке **Environment** добавьте переменную:
   - `DATABASE_URL` = ваш connection string из Neon (тот же, что в `.env`).
5. Нажмите **Deploy**. Render соберёт и запустит сервис — сайт будет доступен по адресу
   вида `https://your-app.onrender.com`.

Готово: сайт публичный, комментарии одинаковые для всех посетителей и сохраняются
навсегда в Neon Postgres — не зависят от браузера, устройства или сессии Claude.

## Примечания

- Свободный тариф Neon хранит данные постоянно, но сам инстанс базы может "засыпать"
  при простое — первый запрос после паузы будет чуть медленнее, это нормально.
- Свободный тариф Render "засыпает" сервис при простое — первое открытие сайта после
  паузы тоже займёт несколько секунд, пока сервис поднимается.
- В `server.js` включён простой лимит длины (имя ≤ 40 символов, отзыв ≤ 300) и базовая
  защита от пустых полей — при желании добавьте капчу или rate-limit для защиты от спама.
